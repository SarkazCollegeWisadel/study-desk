# 开发与维护

公开源码基于 2026-09-29 前端状态及 2026-10-09 本机后端源码整理。私人工作笔记、画像、日志及教材未发布。

## 数据协议

章节切片名称：`12-第十二章-章节标题-P201-216.md`。
分步单元名称：`U033-第十三章-章节标题-01-P246-253.md`。
桶卡基本表头：`Q,A,Tag,Hook,Source`；兼容情况见 `unit_api.py` 和 `drill_api.py`。
缺口表位于 `学习记录/缺口_<科目>.md`，通过章号归属关联章节。
学习日志以 `## 单元记录 YYYY-MM-DD` 标题解析，制作笔记不计入学习进度。

标签仅使用【推】【半】【桶】；名解练习需要有权使用的教材原句。公开示例说明操作，不冒充医学教材原句。

## 开发边界

- 运行环境的配置根目录不要随意改变，索引 ID 依赖相对路径。新安装时可以配置自己的资料根目录。
- 导入只复制，写入保持在配置根目录内。
- 保留自定义光标、轨道导航、时钟入场、滚动圆环和音效开关。原生 dialog 使用系统光标。
- 音效默认关闭；音乐隐藏画面，停止才卸载播放器。
- `drillSessions` 按模式保留独立状态，迟到响应仅更新所属会话。页面暂存不等于学习日志落盘。
- 修改 Anki 模板或示例后检查正面隐藏答案、背面完整、字段转义与空 sandbox。
- 学习台的 8765 端口不能当作 AnkiConnect；两个服务需不同端口。

## 验证约定

只读查看可使用 `http://127.0.0.1:8765/#dry`。首页精确匹配，不用 `/?dry=1`。
名解检查使用 `save:false`，扫描判卷使用 `dry:true`。桶卡评级存在不完全遵守 dry/save 标志的限制，应使用隔离数据与模拟接口，不能在真实私人卡片上评级测试。

前端更新后仅刷新可能仍看到缓存版本，需用既有方式重启专属服务。先核对监听 PID，不批量结束 Python、Ollama 或 Anki。

公开版将私人内嵌 Anki 数据替换为原创示例并移除个人卡包。这是与私人运行版有意保留的差异；后续同步不能直接推送私人 HTML。
