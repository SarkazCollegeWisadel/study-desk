# Study Desk · 学习台前端

个人学习台的网页前端，围绕「选题 → 推理链 → 证伪 → 大纲落点 → 桶卡 → 下次问题」组织学习记录。

## 当前界面

- 蓝色斜切页面推进与方向速度线；目标页准备完成后再揭开。
- 学习入场采用旋转时钟、指针和题目转场。
- 自定义鼠标引导与点击定位点；引导可见时隐藏系统指针。
- 分层卡牌选课、模型选择面板、推理记录步骤索引。
- 保留轻量动效、减少动态效果与窄屏布局支持。

## 文件与使用

`kb/web/index.html` 为单文件前端。它依赖现有学习台同源 `/api/*` 接口；本仓库不包含后端，因此不能作为独立静态应用直接运行。

将该文件放回现有学习台的同名路径。当前本地服务在启动时缓存 HTML，修改文件后需重启服务再刷新浏览器；仅刷新不会加载磁盘上的新版本。

本仓库只保存前端代码，不包含模型密钥、个人学习记录、知识库索引或参考图片与视频。

## 验证

发布前在隔离浏览器中验证了页面切换、加载等待、时钟入场及取消、草稿恢复、自定义鼠标显示与失焦/触屏恢复，并核对了本地 `http://127.0.0.1:8765/` 返回的 HTML 与源码一致。
